## Управление лампой

### Включение

1. Подключите кабель питания к разъёму USB Type-C на нижней части лампы, а другой конец — к сетевому адаптеру или USB-порту
2. Дождитесь полного запуска лампы (зеленая строка – анимация загрузки)
3. Лампа включена! Засветится одним из случайных шаблонов

### Сенсорная кнопка (центр верхней панели)

- **1 касание** — ВКЛ/ВЫКЛ матрицы лампы
- **2 касания** — смена шаблона свечения
- **Удержание** — первое удержание плавно уменьшает яркость вплоть до выключения; второе удержание — увеличивает яркость до максимума

### Через смартфон

> ⚠️ При подключении лампы к устройствам Apple возможны проблемы с подключением

1. Включите на смартфоне Wi-Fi и найдите сеть **AziLamp**
2. Подключитесь к этой сети, используя пароль **12341234**
3. Перейдите в любой браузер и в адресную строку введите **192.168.4.1**

Панель для дистанционного управления открыта!

## Сборка

Проект собирается через Arduino IDE или arduino-cli:

- Плата: ESP8266 (Wemos D1 mini / NodeMCU)
- Частота: 160 MHz
- Flash: 4MB
- Библиотеки из папки `libraries/`

## Прошивка

### Linux

```bash
./flash_lamp.sh /dev/ttyUSB0
```

Или без указания порта (автоопределение):

```bash
./flash_lamp.sh
```

### Windows

Запустите двойным кликом:

```cmd
flash_lamp.bat COM3
```

(Порт COM смотрите в Диспетчере устройств → Порты)

### Ручной BOOT (если прошивка не стартует)

1. Зажмите кнопку **FLASH** и держите
2. Коротко нажмите **RST** (не отпуская FLASH)
3. Отпустите **FLASH**
4. Сразу запустите скрипт прошивки

## Что делать, если...

### Кнопка не реагирует на касания

1. Убедитесь, что касаетесь кнопки точно по центру верхней панели лампы
2. Проверьте, что кнопка исправна: загляните под верхнюю панель, там будет гореть красный светодиод при касании

### Шаблон не переключается (или переключается между одними и теми же)

1. Проверьте, что одним касанием кнопка включает и выключает матрицу
2. Двойным нажатием установите шаблон, при котором лампа светит ярким белым цветом
3. Удерживайте кнопку около 2-3 секунд, чтобы снизить яркость матрицы
4. Сразу после этого сделайте двойное касание, чтобы переключить шаблон

### Не получается подключиться через смартфон

1. Убедитесь, что среди доступных сетей Wi-Fi отсутствует «AziLamp»
2. Перезапустите лампу и дождитесь её полного включения (только так вы перезапустите Wi-Fi модуль)
3. Если сеть отображается, но подключиться не удаётся — проверьте пароль: **12341234**

Если ни один из советов не помог — обратитесь за помощью.
